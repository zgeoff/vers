# Game glossary

The terms the game architecture docs share. Each term has one owner, the doc that states its rules,
and the other docs use the term as defined here.

| Term                | Meaning                                                                                                                                              | Owner                                                     |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| activity            | One attempt at one piece of content, recorded as a single append-only checkpoint stream and verified as a unit.                                      | [game simulation](./game-simulation.md)                   |
| activity start      | An activity's first record, naming the node, the seed, and the version stamps; the client builds it and the server admits it.                        | [game simulation](./game-simulation.md)                   |
| activity type       | What the avatar does in an activity; it supplies the code that advances the simulation.                                                              | [game simulation](./game-simulation.md)                   |
| appended anchor     | How far the player claims to have played one chain, and where a new activity begins; the per-activity counterpart is the appended head.              | [seed chain](./seed-chain.md)                             |
| appended head       | How far the client has written one activity's stream; the chain-wide counterpart is the appended anchor.                                             | [game simulation](./game-simulation.md)                   |
| avatar key          | The per-avatar key rolled content derives under; the server holds it under trade custody.                                                            | [game entropy](./game-entropy.md)                         |
| build snapshot      | The avatar's equipment, passives, and level pinned as a simulation input; the client predicts it and the server re-derives it.                       | [game simulation](./game-simulation.md)                   |
| cell coordinate     | The address of one hex cell, and a node's stable id.                                                                                                 | [world map](./worldmap.md)                                |
| chain index         | A checkpoint's absolute position along the whole chain, counted from genesis and never reset by a new activity; reward coordinates key on it.        | [seed chain](./seed-chain.md)                             |
| chain position      | One point on a seed chain: a seed and a chain index.                                                                                                 | [seed chain](./seed-chain.md)                             |
| chain scope         | The stable place an avatar leaves and returns to; a world-map encounter's scope is its map node.                                                     | [seed chain](./seed-chain.md)                             |
| checkpoint          | One recorded simulation step, keyed by its activity and its position in the stream, linking the previous checkpoint's hash.                          | [game simulation](./game-simulation.md)                   |
| chunk coordinate    | The address of one square of hex cells, and the unit the map generator works in.                                                                     | [world map](./worldmap.md)                                |
| cleared frontier    | The set of nodes whose first clear has verified; the reachability check in replay reads this boundary.                                               | [world map](./worldmap.md)                                |
| content plane       | Everything that also needs the scope secret: a node's sealed reward and encounter pool. Server-only.                                                 | [world map](./worldmap.md)                                |
| continuation        | An activity that resumes a chain scope from a prior attempt's appended position, in the same chain.                                                  | [game simulation](./game-simulation.md)                   |
| craft position      | The position a crafting roll commits at, distinct from a reward coordinate.                                                                          | [crafting entropy](../../game-design/crafting-entropy.md) |
| encounter           | The fight an activity runs at its node; completing it clears the node.                                                                               | [game simulation](./game-simulation.md)                   |
| entropy source      | A source of random outcomes: the seed chain, an avatar key, or sealed salt.                                                                          | [game entropy](./game-entropy.md)                         |
| fast-forward        | Reconstruct a gap by deterministically re-simulating the elapsed time from the last known position.                                                  | [offline reconcile](./offline-reconcile.md)               |
| first clear         | The one-time grant recorded when a node's clear verifies; it opens the node's neighbours.                                                            | [offline reconcile](./offline-reconcile.md)               |
| forward-exited      | Said of an activity that left active play with honest progress behind it: a terminal checkpoint, a player stop, or an offline cap.                   | [seed chain](./seed-chain.md)                             |
| genesis seed        | The seed a chain starts from, which the server mints the first time it reveals the node.                                                             | [seed chain](./seed-chain.md)                             |
| geometry plane      | Everything derived from `userSeed` and a coordinate: positions, edges, difficulty, biome. Public and client-computable.                              | [world map](./worldmap.md)                                |
| head row            | The single record holding an activity's live state: its two cursors, its writer, and its status.                                                     | [game simulation](./game-simulation.md)                   |
| keyed PRF           | A pseudorandom function `f(key, coordinate)` whose revealed outputs carry no predictive power over unrevealed coordinates.                           | [game entropy](./game-entropy.md)                         |
| look-ahead          | Simulating a reachable future offline to inspect its outcome before committing to play it.                                                           | [game entropy](./game-entropy.md)                         |
| map reveal          | The region a player has earned sight of: a union of hex discs over the avatar's verified first-clear nodes and the origin, derived and never stored. | [world map](./worldmap.md)                                |
| node                | A place on the avatar's map, and the target one activity is an attempt at.                                                                           | [world map](./worldmap.md)                                |
| offline budget      | The per-avatar simulated-time meter, refilled at wall-clock rate and debited per accepted batch.                                                     | [game simulation](./game-simulation.md)                   |
| parked              | Held because the server cannot replay the activity yet; an operator or a later deploy releases it.                                                   | [replay verification](./replay-verification.md)           |
| predecessor         | The avatar's immediately-prior activity across every chain, stamped by the device at start; the verifier waits for it before adjudicating.           | [offline reconcile](./offline-reconcile.md)               |
| provenance          | An outcome's recorded security property, which decides tradeability; stamped from server records and the `entropySource` tag.                        | [game entropy](./game-entropy.md)                         |
| quarantined         | Held because the activity's divergence failed to reproduce too many times; an operator releases it.                                                  | [replay verification](./replay-verification.md)           |
| reward coordinate   | `(avatarID, scopeType, scopeID, chainIndex, ordinal)`, the deterministic position a rolled reward commits at.                                        | [game entropy](./game-entropy.md)                         |
| reward reveal       | The server's disclosure of a coordinate's rolled content, which happens only once the verifier settles its checkpoint.                               | [replay verification](./replay-verification.md)           |
| rolled reward       | A reward whose value lives in its roll, committed at a coordinate and revealed later under a key; an item drop is the concrete case.                 | [game entropy](./game-entropy.md)                         |
| scope secret        | The per-avatar secret the server holds and never ships; without it `userSeed` derives no content.                                                    | [world map](./worldmap.md)                                |
| sealed descriptor   | The keyed digest a node's contents derive from, uncorrelated with anything on the geometry plane.                                                    | [world map](./worldmap.md)                                |
| seed chain          | One forward sequence of chain positions per avatar per chain scope; each activity draws positions from it and never draws one twice.                 | [seed chain](./seed-chain.md)                             |
| segment             | The run of checkpoints under one sim version that the verifier adjudicates as one piece; each segment settles what it proved.                        | [replay verification](./replay-verification.md)           |
| settle              | The server applies an activity's proved rewards to the avatar. A reward shows as pending until then.                                                 | [replay verification](./replay-verification.md)           |
| sim snapshot        | The engine's serializable projection of the running simulation, which viewer tabs render.                                                            | [game simulation](./game-simulation.md)                   |
| sim version         | The engine build's version stamp; it pins which code replays a segment.                                                                              | [replay verification](./replay-verification.md)           |
| travel selection    | The set a player may travel to: the origin, cleared nodes, and every node an edge joins to a cleared node.                                           | [world map](./worldmap.md)                                |
| `userSeed`          | The avatar's own seed. Not a secret, shipped to the client, and an input to both planes.                                                             | [world map](./worldmap.md)                                |
| verified anchor     | How far the server has proved one chain, where a rejection rewinds to; the per-activity counterpart is the verified head.                            | [seed chain](./seed-chain.md)                             |
| verified head       | How far the verifier has replayed and trusted one activity's stream; the chain-wide counterpart is the verified anchor.                              | [game simulation](./game-simulation.md)                   |
| verifier            | The server process that replays a submitted stream to decide whether to trust it.                                                                    | [replay verification](./replay-verification.md)           |
| world-map encounter | The activity type where an avatar fights through a map node's enemies, arranged in waves.                                                            | [game simulation](./game-simulation.md)                   |
| writer worker       | The one worker per browser profile that runs the simulation and appends its checkpoints.                                                             | [offline reconcile](./offline-reconcile.md)               |
