VERS  /  AETHER DESIGN SYSTEM

The system, not the screens

The living reference for Vers’ visual language. Screens will change as the game is built — this holds the rules that shouldn’t: colour roles, type, component patterns and motion. Copy values straight from here. The screens at the bottom are canonical examples of the system applied, not the source of truth.

Deliberately excluded: a naming glossary. Terminology (aether / nexus / stratum / barrier…) is still in flux and will settle as the game design does — capturing it now would just create a stale reference to maintain.

01COLOUR

Colour is semantic, not decorative. Three roles carry meaning everywhere: teal = the world / aether, gold = you / your character, violet = the enemy / arcane. Everything else is a supporting accent or neutral.

04MOTION

A small vocabulary of named, looping behaviours. Combat surfaces animate a single “turn” on repeat so they read as alive at rest; everything else is subtle ambient drift.

Ability/cast bars fill then fire. Staggered timings per actor.
