Projectile Family — 8 skills, 1 skeleton

Every glyph below shares one rule set, so coherence is structural, not curated. Each glyph's silhouette draws its mechanic — pierce looks like piercing, chain looks like bouncing — so distinguishability is semantic, never arbitrary.

THE SKELETON

what makes 8 glyphs read as one family

One shared travel axis: everything launches bottom-left and lands top-right. Plus a fixed grid and stroke. That's the entire coherence budget — no shared shapes required.

TRAVEL AXIS ↗
grid 24×24 live area 20×20 (2px padding) stroke 1.5 caps + joins round fills none (dots ≤ r1.6 exempt) color currentColor only silhouette encodes MECHANIC — linear, fan, pierce, chain, homing… color encodes ELEMENT — applied by the slot, never baked into the path container encodes RARITY / STATE — border, glow, shape of the slot

DENSITY LAB

why tier 10 got muddy, and the rule that fixes it

The old waist chevron sat ~1.8 units from the shell — at stroke 1.5 that leaves ~0.3 units of ink gap. It was spacing, not weight. Four candidate fixes below at tier 10; the strip above already runs on the adopted rule.

ORIGINAL CHEVRON HUGS SHELL
A · RESPACE ADOPTED
B · THIN ORNAMENT REJECTED
C · GROW OUTWARD ADOPTED

The codified rule (A + C): parallel runs keep ≥2.5 units centre-to-centre · point or diagonal approaches keep ≥2.0 · perpendicular ticks either join fully or stop ≥1.5 short — never hover closer · the interior caps at 4 ornament groups, and every tier past the cap grows outward (pauldrons, spikes, aura). B is rejected as a density fix — spacing must be solved by geometry. Weight-as-hierarchy is a separate question, tested properly in the Stroke Weight Lab below.

REGISTER LAB

why the gear felt off — same helm, three registers

The psycaster helm works because it's drawn as a sigil — abstract geometry, same language as the UI's hexes and diamonds. The old gear was drawn as pictograms — tiny literal pictures of medieval objects — which is why it read as generic-RPG and fought the interface. The adopted register is the middle one: schematic — a geometric shell plus one function line, like a mech loadout screen.

Pictogram
REJECTED

a drawing of a bascinet — medieval noun, generic-RPG read

Schematic
ADOPTED

geometric shell + visor band — slot-recognizable, era-correct

Sigil
TOO FAR

reads as UI, not item — and collides with the hexes enemies already own

Era rule joins the contract: forms come from this world's tech — visors, plating, treads, antennae, projections — never the medieval armoury. Skills stay symbolic (they're verbs); gear goes schematic (they're objects); psycaster gear is the licensed exception that leans sigil, because that is its fiction.

STROKE WEIGHT LAB

thick shell + fine detail — tier-6 gauntlet, three systems, each at 24px

Hypothesis: a heavier base silhouette makes room for finer ornament. Tested on the densest glyph we have. The small chip under each is the 24px loot-grid render — the survival test that decides it.

UNIFORM 1.5 FLAT HIERARCHY
SHELL 2 · DETAIL 1.4 ADOPTED — GEAR ONLY
SHELL 2.2 · DETAIL 1 DETAIL DIES AT 24PX

Verdict: the hypothesis holds — with one boundary. Two weights give gear real object-hierarchy (silhouette pops, ornament recedes) and buy back density headroom. But detail below ~1.4 evaporates at loot-grid scale, so the ratio is capped: shell 2 / detail 1.4, gear register only. Skills stay uniform 1.5 — they're UI symbols, render down to 14px beads, and a bold/fine split there reads as inconsistency, not hierarchy. Spacing is still solved by geometry — weight is hierarchy, never a density fix.

ONE SLOT, THREE FORM LANGUAGES

helmet × archetype — the fifth channel

Archetype doesn't get new slots or new gates — it gets a form vocabulary that every glyph of that archetype is drawn in. Because the vocabulary applies across all eight gear slots, a mixed build reads as visually mixed for free, and a full set reads as a uniform.

JUGGERNAUT

THE CONTRACT

this text block IS the tooling — it prompts every future batch
# vers glyph contract · v0
grid        24×24 · live area 20×20 (2px padding all sides)
stroke      skills: uniform 1.5 · gear: shell 2 / detail 1.4 (detail never below 1.4 — dies at 24px)
            round caps · round joins · no fills (dots ≤ r1.8 exempt; paired dots banned on face zones)
color       single currentColor per glyph — tint belongs to the slot, never the path
gate        a glyph ships only if it survives: 14px render · monochrome · a one-word description
density     parallel runs ≥2.5 apart · point approaches ≥2.0 · perpendicular ticks join or stop ≥1.5 short
            interior caps at 4 ornament groups — tiers past the cap grow outward
            spacing is solved by geometry, never by thinning strokes — weight is hierarchy, not a density fix

register    skills are SYMBOLS (verbs) · gear is SCHEMATIC — geometric shell + one function line, never a pictogram
era         forms come from this world's tech: visors, plating, treads, antennae, projections — no medieval nouns

# channels — each fact of the game owns exactly one visual variable
silhouette  MECHANIC or SLOT (pierce / chain / fan · helm / belt / ring)
ornament    TIER — tier 1 is the naked silhouette · tier N = tier N−1 + one stroke group, outline frozen
element     COLOR only · rarity / state owns the container (border, glow, slot shape)
archetype   FORM LANGUAGE — juggernaut: slabs + vents · psycaster: arcs + floating · scoundrel: asymmetry + optics
            floating elements belong to psycaster ALONE — all other ornament attaches to the silhouette
            exception: jewelry (ring / amulet) may orbit — arcs must leave gaps where later tiers land

# family skeletons — the only per-family decision
projectile  travel axis ↗ 45°, whole family
area        no axis — anchor: radial (self) or ground ellipse
gear        closed silhouette · vertical symmetry (profile slots exempt)
