# Improve the process

When a correction repeats, change the rule and not the memory. The owner declining the same class of
proposal twice, or a rule producing a wrong edit, is the trigger.

- A rule in this skill: a PR editing the role file.
- A triage rule: AGENTS.md's Issue hygiene section and `scripts/src/issue-hygiene/check-issue.ts` in
  the same PR.
- A label: `infra/github.ts`.
- A template: `.github/ISSUE_TEMPLATE/`.

Propose the rule change in Report first, and write it on yes. Open the PR from a worktree under
`.worktrees/` with a Conventional Commit title, and load the `docs-writing` skill before editing
prose.
